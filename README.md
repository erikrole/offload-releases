# Offload

Offload gets Sony FX6 and FX3 clips off the card safely, names them from the play-by-play, and files them in the archive.

**Download:** [Offload.dmg](https://github.com/erikrole/offload-releases/releases/latest/download/Offload.dmg) (latest release, notarized by Apple)

## Install

1. Open the downloaded disk image and double-click **Offload**.
2. When it asks "Move Offload to Applications?", choose **Move to Applications**.
3. A short tour opens the first time.

Requires macOS 15 or later. For playing FX6 (MXF) clips, install Apple's free *Pro Video Formats*; copying and naming work without it.
